# 40画像覆盖协议 v2（作者拟定，待独立复核）

2026-11-05先定义本协议，再执行。原ZIP `02_catalog_spec.md` 第5节明确统计“有依据的学习与参赛路径”，不保证全年均有三场开放报名。冻结40画像不改动：预算、可用设备、队友、导师实验室、明确排除条件保持原值；全部画像有个人预算上限，不能默认未知费用满足。

原`strictCoveragePassed`及`strictRate`继续只表示当届正式参与资格、个人总费用已证实的覆盖。历史资格和报名费不替代当前资格与总费用；0/40原结果保留。新`preparationCoverage`只统计具体官方历史题或完整公开作品支撑的准备任务，不表示可报名、正式交付达标、获得评分或已有技能。

每个准备方案必须人工逐条编写（本轮由作者代理编写，非独立审阅）：精确系列与赛道、具体原题来源ID、个人角色、可检查输出、任务类型、小时上界、已有设备要求、是否需要队友/导师/实验室、增量支出上界及依据、专业/语言适用限制。预算估计明确标为`editorial_inference`，不能转存官方费用事实。零增量仅用于已有电脑/手机、已展示的公开材料、离线手算/文字/图表分析，不买硬件材料、不购软件、不调用付费模型、不发起实地活动；不包含重新购买已有设备或日常生活成本，不声称完成整个竞赛。

计数同时要求：精确记录L2及以上；完整代表任务的来源已正文读取；正文来源无待重查标记；非赛事概述/空主题；方案资源均由画像明确提供（可联系队友不是已有队友）；所需预算和小时均在上限内；方案的经验/语言/专业边界及画像明确排除项满足。未知预算、额外购买、未知前置知识/语言/专业、现场设备、实验室、导师、隐含付费服务均不计通过。仅证明/手算准备不声称已经具备正式参赛资格。

保留作者草稿与独立验收两个状态：执行结果是`author_assessed_pending_independent_review`，只支持定位覆盖缺口；独立评审未完成前不宣布90%验收达成。逐画像输出已计/被拒准备方案及原因。至少3个不同系列、至少2种实质不同任务/角色路径才通过该画像。系列多题不重复计数。原正式参与指标、准备路径指标与两者并集分开报告，不能用相关系列数量替换可行路径数量。

特殊画像按其具体兴趣与约束检查：历史史料、教育讲解、农学无实验资源、法学中文论证。不通过一般任务族匹配强行覆盖；只有方案显式支持相应特殊画像才计入。未来新增方案必须重新执行并更新协议方案摘要，既有目录指纹相同但方案变化也使旧结果失效。

完整公开作品的作者/期刊来源可支持学习任务，即使不是赛事官方；必须是 `published_work` 且该来源被完整案例直接引用。该例外不适用于作品获奖摘要或编辑练习，也不能据此批准任何官方资格、收费或当前报名事实。
