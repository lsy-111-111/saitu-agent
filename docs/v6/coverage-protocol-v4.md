# 严格参赛覆盖协议 v4（工程候选，待独立审查）

v4根据独立政策裁决区分官方规范与编辑可行性推导。保留原40画像、个人预算与资源事实、36/40目标、每画像3独立系列/2实质路径，以及准备覆盖的独立统计。保留所有v3历史结果；目录audit拒绝旧协议或旧实现摘要。没有给真实记录新增推导，也不构成真实路径批准。

当届报名条件仍要求现有currentRegistrationVerified：适用官方报名事实、当前发布审核、status=open、核验时间非未来且不超过72小时。用户尚未裁定是否可含未来正式规划，v4不擅改该时间口径。费用和时间证明不能替代资格eligible。

## 官方规范与分析合同

旧participationRequirements六字段继续解析，未知须显式null。teamSize仍须适用当前官方规则；导师、实验室、设备、出行默认也须官方证据。可组队、可争取导师/实验室不等于已落实。旧weeklyHours标量只有显式meaning=official_complete_path_weekly_bound才可作完整周投入上界；official_event_duration或未标注标量不能代替全部完成工时。未标注旧数据不被误判格式非法，只是不足以证明严格覆盖。

新participationPlans是可选数组，每个计划须符合saitu.formal-participation-plan.v1：
- 绑定record.scope、profileId及整个原画像的规范化SHA256。不同画像、不同约束、不同前提不得复用旧推导；多个相同画像计划歧义也不通过。
- path列完整正式路径、全部阶段和交付物、退出条件。stage集合必须精确匹配record.stages，并引用当前适用participation.formalPath官方闭包事实与每阶段依据；包括必需后续/晋级阶段。不能用学习体验或只完成初赛替代。
- prerequisites明确个人角色、1人完成前提、已有经验、引用画像实际经历和已有设备，额外尚未确认条件不得通过。不会从预算或resources枚举推导网络、付费软件、导师、实验室或队伍。
- resourceDerivations可明确标识对导师/实验室/设备/出行的编辑分析，逐结论引用editorial_inference事实与完整官方流程依据，绑定原六字段。未提及某资源不是自动无需求；完整性仍必须由独立审者逐源判断。

整段计划、事实和来源进入既有catalogContentDigest。严格使用计划必须通过hasDualAiReview，并由当前摘要的两位不同独立审者/不同运行覆盖计划全部来源；不接受作者或调用者给的approved布尔值，也不沿用修改前的批准。正式记录的真实认证由既有独立导入工作流负责；单元测试中的合成标记不是任何真实批准。

## 工时

workload分为editorial_estimate和official_complete_path_bound。编辑估计明确方法、每阶段完整交付任务、角色、每任务分钟区间、学习与返工余量、官方固定时段、按UTC日历周分配的各任务上界。所有任务上界须完整分配，不能漏任务、重名或藏在均值里；声明峰值必须等于实际逐周最大和。固定连续赛段按真实起止时间落入周，分配不得低于该周连续赛段；跨周时按实际重叠时间计入。峰值与画像每周上限比较，官方2小时赛时不自动等于总投入2小时。

官方完整路径周上界也必须明确全路径范围、逐周上界及当前来源。其含义是官方限制完整必做投入的上界，不是作者把比赛时长改标签。两种路径都不保证个人完赛或获奖。任务完整性、区间合理性、日期、角色及来源语义须双审；代码不靠关键词猜测原文是否支持估计。

## 费用

保留旧直接官方personalTotalCost路径，另接受计划内两种明确类型：
1. direct_official_total：当前适用官方事实直接支持全程个人必需支出上界，覆盖全部阶段、全部费用类别与有效期，不能留未解释例外。支持investment、cost等总支出事实，不要求唯一专用字段；fee单项不能冒充总额。
2. component_sum：逐阶段交代报名、材料、工具/平台、网络、计算、寄送、出行、食宿及其它必需费用。每项明确paid/owned/not_required、来源、说明、数量、单价上界（整数分）与覆盖整个计划的价格适用期。主办方报名费用organizer_fee，其他有界公开价格用public_price_upper_bound；起步价、平均价或无限上界不合法。

owned只能引用该画像实际已有设备，并说明本次无新增支出；not_required须有完整流程闭包依据和双审，不能因页面沉默推零。远程路径不能把网络列为not_required；固定画像没有已有网络，不能补为owned。公开可购买服务的价格和适用前提也须原文约束、同范围审查，不能假定赠送、报销、补贴或队友分摊。

总额用BigInt分乘数量再求和，超过安全整数或任何分项null均拒绝。人民币预算只接受可精确转换的非负两位以内小数，不舍入漏计。任何阶段/类别缺口、错范围、过期/冲突、未知上界或画像前提不符，不能通过费用判定。已证费用与工时可行性分别报告；费用明确但周峰值超限仍不能计严格覆盖。

## 目录验证与不确定性

新合同格式错误或悬空引用仍为结构问题。合法但未闭合的参与估计产生strict_participation问题，不把诚实编辑分析当成缺官方事实的L2错误，也不污染独立的报名事实验证；assessStrictParticipation仍逐项拒绝未证条件。真实记录没有新合同不会自动得到任何新通过。

CLI输出继续绑定完整实现摘要并检查运行中源码未变。目录audit精确接受v4及当前实现/目录/画像匹配结果，不接受v3历史结果伪装当前测量。协议、真实路径、完整原件、费用与工时推导仍须后续独立审查；作者测试通过不签发36/40验收。
