# 严格参赛覆盖协议 v3（实现候选，待独立复核）

保留v2的原40类画像、预算、队伍、设备、3个独立系列和2条实质路径，以及准备路径的独立统计。v2历史文件与失败结果保留。v3补齐严格参赛分支缺少的资源和时点检查，不把准备任务计入严格36/40。

严格候选必须同时满足：适用资格eligible、个人总费用上界有当前原文依据并在预算内、当届报名经72小时内核验与所选审核政策确认，以及明确资源条件可行。零报名费不能证明全程个人费用为零；费用证据至少包含personalTotalCost字段，不能把fee单项改名为总额。

participationRequirements逐字段记录teamSize、mentor、laboratory、equipment、attendance、weeklyHours的明确值及factIds。每项绑定同届次、赛道、组别、范围的participation.<字段>当前官方事实；缺失、历史、未知及跨范围依据均不通过。字段值须来自实际原文与独立审核，不得仅为了满足结构补值。所需人数组不支持“可组队”代替现有队友；画像中的导师和实验室为可争取资源，不能当已落实。设备必须已知具备，差旅与时间须在原画像边界内。

该结构用于显示还缺哪些证据，不说明公开规则必然不包含这些信息。新字段加入正文后会改变内容摘要，旧批准不自动继承。现有资料缺该结构时仍可具有历史L2/L3学习价值，但严格参赛状态是unknown。

每个候选输出participationFeasibility及拒绝原因。CLI结果绑定完整实现摘要并检查运行中源码未变；目录审计拒绝旧协议或不同实现的覆盖结果。计算结果仍需独立语义审核，不能据字段合法或自动测试通过自行签发36/40验收。
