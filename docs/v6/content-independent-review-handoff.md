# 内容独立审查交接

这是本地、非封存的作者审查入口，不是公开互联网发布，也不把外部整篇原件授权为可公开转载。入口为 `artifacts/v6/content-review/index.html`，完整数据在同目录 `review-pack.json`。生成命令为 `node scripts/competitions/v6/build-content-review-pack.mjs`；来源、正文和目录摘要均绑定生成时的真实文件。目录继续修改后应重新生成并重新核对审核内容摘要。

所有作者草稿仍待审核。当前内容审查不得由原作者 `/root`、`/root/audit_catalog`、`/root/research_b` 自审通过；两位新审核者应在各自独立上下文实际打开所采用的官方正文或完整公开作品，不以作者摘要、冻结成功、哈希一致或脚本判定代替真实性判断。保留 `humanReview.status=not_performed`，授权的真实 AI 双审与人工政策分开记录。逐条审核必须绑定 `catalogContentDigest`，改动后的旧审批失效。

## 原合同与缺口分级

依据用户提供 ZIP `saitu_upgrade_v1/02_catalog_spec.md`，第1节要求“官方评分维度/权重；缺失时明确未知”及“不发明官方权重”；第4节 L3 要求代表性题目解析、公开作品拆解、评分映射、角色路径与经审核备赛建议；第5节统计“有依据的学习与参赛路径”，不保证随时有三场开放报名。后续用户明确采用具体已读官方题目或完整公开作品及真实 AI 双审。

因此，官方适用评分维度已读、但未公布数字权重，不必自动等同于没有任何评审依据；是否足够仍须审者查原文及实际映射。相反，跨届或跨赛区评分、关键资格未读、只有摘要而非具体题目/完整作品、没有适用官方评审依据，均不能通过声明“限制”自动消除。`deep-gap-assessment.json` 是作者提出的 `mandatory_missing`、`declared_limitation` 或 `mixed_pending_review` 分类，附具体来源和合同依据，**不是审核结论**。现有 `missingForPublication` 不因分类建议而清空；只有真正补证或独立裁定后按证据修改。

已补证变更保留在 `artifacts/v6/content-research/gap-repair-reading-log.json`：三创补读同届14页实施方案和完整附件，补齐100分映射与6+4+4周，四周计划改为前期准备；CFA补读封面明确2024—2025的规则及同届评分，和2025公开报告对齐，移除以当前2026—2027规则支持历史例子的混届关联。这两项仍是作者草稿，没有任何审批。

## 逐记录审查

每份草稿包括系列、记录 ID、届次/赛道/组别/范围、作者、完整内容、资格规则、主要事实、来源原件和正文路径、SHA256、实际作者读取位置与未解决项。请分别检查：

1. 实体独立性与适用范围，禁止系列、赛道、企业命题、平台重复计数；地方和历史条件不得扩展。
2. 每条官方事实在确切正文中有支持，复合事实各子句都有证据；来源作用域不能仅由机器字符串匹配决定。
3. 深度内容确为具体官方题目或完整公开作品；作品摘要、泛命题练习和未读附件不能算。作品作者与竞赛官方身份分开。
4. 评分映射是同届同赛道可适用维度；要求、评委标准、数字权重不能互相冒充。缺权重但有适用维度须说明可用边界。
5. 学生能说明实际动作、个人贡献、四周前提、失败与退出条件；准备片段不能宣称正式完成。预算资源未知保持未知。
6. 时间来源、报名状态、费用、AI使用和知识产权的表述符合正文；当前可报名另有72小时与发布政策门槛。

每位审者独立留下源定位、结论、严重程度及待改项；不要预填approved，不以作者完整字段数作为合格数。要求改动的记录须修改后再审，不能原摘要审批后改正文。

## 500事实抽核

`fact-check-candidates.json` 收集声明已读官方来源的事实，按句号/分号生成待审句段，保留完整原句、实体、事实 ID、来源及冻结哈希。`fact-check-500-proposed.json` 从确有可校验冻结正文的候选中按系列轮取500条，使用公开 SHA 顺序，可重现但不是隐藏测试集。

**候选句段不等于已经审过的500个原子事实。** 审者必须将复合句拆成可独立判断的断言、去除重复及纯编辑限制，把“未给费用”等否定声明也按足够完整来源核查；记录真实独立事实分母、每条支持/不支持/未知和错误率。抽样命中不足500个独立可核断言时继续从全集补足，不能将机器分句数当完成。凡缺正文、访问被拒、只留下图片或局部DOM，保留具体限制，可打开原件另核，不能假称已核。

`captureKind=rendered_dom_text` 表示真实浏览器观察的公开文字，哈希只绑定该次DOM截取，**不是服务器原始HTML字节**。原件字节、提取正文和作者读取局部范围分别保留；冻结了整份文件不代表作者读过整份。个人数据、公开作品许可和来源版权限制仍按原来源处理，未经允许不把本地原件审查缓存发布到网站。
