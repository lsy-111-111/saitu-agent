# 学生理解试用材料

状态：可组织试用的材料；尚未招募、未收集结果，不能据此声称产品理解效果通过。

## 邀请与参与说明

我们正在检查赛途是否能帮助本科低年级和竞赛新手理解自己的选赛方向。参与者体验问答和推荐后，完成五道与该报告相关的选择题。参加自愿，可以跳过问题或退出；不会要求报名、购买辅导或提供成绩证明。使用匿名编号记录结果，联系方式（若自愿接受后续联系）与研究表分开保存。实际AI处理以站内当前同意说明为准，不使用旧版本同意替代。

记录表为 `artifacts/v6/evaluation/student-study-observations.csv`，目前只有字段，没有参与者和分数。研究负责人应先填清数据用途、保留期限、联系与退出方式，向参与者展示并记录同意，再开始招募。

## 分阶段组织

先做约12人的可用性试验，覆盖六个任务族，找出问题歧义、阅读负担与实际耗时；该轮用于改设计，不作最终效果认证。正式研究以至少60人为排产起点，结合试验方差和最小有意义差异确定人数；60本身不是统计保证。确定分组和评分口径后再开始正式研究。

新旧流程采用随机分组，或在等价情境下平衡体验顺序，避免第二次只是记住答案。独立评分者不知道系统版本。计入退出者，分别报告开始人数、完成人数、放弃原因及耗时分布。

## 五道选择题模板

以下占位内容由独立人员依据学生确认画像和竞赛原文填写，不直接抄系统报告作答案。每题20分，只选一项；选项位置轮换。

1. **本次推荐最具体的依据是什么？** A 学生实际做过的某项任务与赛道交付相连；B 比赛名字听起来更有名；C 报名后必然具备某能力；D 学生感兴趣就已经熟练。替换A为该画像真实依据，确保其他项不是另一条合理依据。
2. **这个赛道最终主要提交什么？** A 原文规定的交付物；B 同系列另一赛道的交付物；C 只有报名表即可；D 仅参加课程。按真实赛道改写，避免凭常识就能猜对。
3. **学生最需要先解决哪项差距或条件？** A 会改变当前可行性的具体条件；B 已经具备的条件；C 与任务无关的能力；D 无需确认任何条件。
4. **哪种收益是合理而有条件的预期？** A 完成并获准展示后保留作品及本人贡献记录；B 报名保证获奖；C 全国所有学校保证加分；D 企业命题保证实习。A须替换为该赛事有依据的实际收益，不能所有题机械用同一句。
5. **下周最合理的第一步是什么？** A 可执行的小任务与完成检查点；B 同时报名所有推荐；C 在关键条件未知时购买大量设备；D 直接按获奖标准无限备赛。A应由画像条件和任务原文独立确定。

另外请学生用自己的话说：我为什么选择这项、暂时不选另一项、什么条件改变会让我重选。可以不同意推荐；能提出合理取舍也是理解，而非必须接受系统第一名。

## 评分和报告

理解均分目标85/100，可执行下一步目标80%，快速流程完成率目标85%；均须报告真实分母及不确定性。若试验旧系统≤80分，正式研究前可注册提升15分及配对区间下界>0的目标；如果已接近天花板，应在正式研究前改用有区分度的题目或预注册非劣效与误解减少，不能看过结果后换标准。

经另行自愿选择，7–14天后记录是否完成小任务、为何调整方向。合理行动和自我理解是成功证据，强行报名、点击或购买不是替代指标。满意度可以另收，但不覆盖知识误解和资格错误。
