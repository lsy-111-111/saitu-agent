# 赛途 v2 实施与验收入口

> 历史版本记录：本文保留 v2 当时的实现、资源判断与待办，不能作为当前完成状态。后续用户已确认 AI 替代验收、Flash/max 及连续续做；当前合同见 [七类合同映射](continuation-contract-map.md)、[AI代理验收](ai-proxy-acceptance.md)和[24任务台账](../../artifacts/continuation-20261105/task-status.json)。下文的旧模型、两项突出、缺密钥/数据库、人工审核和旧计数不得覆盖这些更新。

这是用户批准的 v2 方案在当前项目中的实施记录，版本基线为 `3fb65140589be510e9db3296e792156e690648a6`，核对日 2026-11-05。目标是帮助本科低年级与竞赛新手理解任务、个人起点、收益条件及下一步。本文中的目标数字不是实测效果。

## 已接入的完整流程

`已确认问答 → 签名会话 → v6 画像 → 精确赛道资格与内容门槛 → 全候选比较 → 固定决策 → 引用与支持检查 → 服务端报告 → 更正重算`。

- 快速/深入模式、最多两段分别确认的经历、零经历任务情境、目标取舍、个人预算与准备周期进入签名会话。未经确认的经历不进入模型证据。保留原有最多三次偏好追问和服务器资格保护。
- 新前端请求 `competition-recommendation.v6`；不带此参数的旧客户端继续得到 v5。服务端从已签名会话生成画像，拒绝客户端自带任意 profile。
- 默认展示五项，可展开到十项，前两项突出。少于五项明确报告资料/任务联系不足。比较两至三项、主动收藏和修改回答后重新请求已接入。
- 未确认的多目标保留两条条件路径，不把其中一个目标偷偷作为优先级。确认取舍后通过正常问答重新签名、重算。
- 更正生成新画像内容哈希；引用对象、缓存键、报告均绑定版本。旧事实在新画像中不存在，因此其引用校验失败。页面用请求代次丢弃过期返回，保留前后变化说明。
- 旧收藏按旧版本读取；v6 收藏另用 `saitu.savedDecisionChoices.v6`，主动保存最多十项/次，累计五十项。保存选择快照，不保存完整问答画像。个性化理由可能包含已确认经历，说明已同步。

## 三种算法与回退

| 方法 | 当前实现 | 使用边界 |
| --- | --- | --- |
| A 规则基线 | 新内容、新资格、新报告；沿用确定性评分；明确任务偏好优先于通用技能 | 当前默认，不能把写作/演讲能力当成对所有赛事的任务兴趣 |
| C 模型整体比较 | 全量摘要，最多二十项详细事实包，最多十个不同系列；个人理由、角色选择与前两项比较固定后再组装报告 | `SAITU_DECISION_STRATEGY=llm` 启用；仍需同条件真实评测后才能决定正式默认方案 |
| B 逐项语义比较 | 全候选五维 0–4/未知，按 30/25/20/15/10 权重计算上下界，并去重系列 | 离线对照；缺失候选视为失败，不能静默截断 |
| D 局部成对比较 | 尚未实施 | 仅当实测表明顺序稳定性成为瓶颈后加入 |

C 的匹配、支持检查是不同调用，但不是独立专家审核。来源里存在链接不代表结论正确：除结构与对象检查外，对模型产生的个人理由、分工依据、比较断言另做语义支持检查。最多一次修复；空白、截断、超时、未知 ID、预算不足或校验失败都回退 A，并说明来源。详细系统提示词和阶段指令在 `src/lib/competitions/v6/model.ts`，不依赖部署人员手工复制提示词。

全量摘要超过 180,000 UTF-8 字节时记录 `context_budget_exceeded` 并回退，不静默丢候选。HTTP v6 阶段上限分别为 AI 38 秒、生产 40 秒、落库 42 秒、重复等待 44 秒、响应 45 秒；这是实现预算，完整结果 p95≤45 秒仍需生产近似条件实测。

## 字段与校验规则

| 对象 | 核心字段 | 不变量 |
| --- | --- | --- |
| 学生事实 | id/field/value/label/state/confirmed/evidenceLevel | 喜欢、自述会、本人具体经历分开；unknown/retracted 不可作为已知依据；经历贡献逐段保存 |
| 学生画像 | profileId/revision/facts/goals/primaryGoal/tradeoffStatus/mode | 只有明确确认才写优先目标；v5 未确认的时间、队伍、经验默认值保持未知 |
| 竞赛记录 | seriesId/recordId/edition/track/group/scope | 推荐按具体赛道判断、展示按系列去重，禁止借其他赛道资格 |
| 赛事事实 | id/text/kind/status/sourceIds/scope/checkedAt | 历史规则与当前规则分开；高校通知不自动扩展全国；冲突、未知、pending_review、未重读或未读取正文的来源不充作正式依据；deep.*案例要求不进入通用匹配事实池 |
| 决策 | profileRevision/catalogVersion/recommendations/roleIndex/roleReason/comparison/shortfallReason | 不能引入库外项、重复系列、过期画像；每项分工来自已有角色目录 |
| 结论 | text/basis/studentFactIds/competitionFactIds/conditions | 事实/推断/建议/未知显式区分；推断要有个人依据与正确赛事依据，收益条件不能被省略为保证 |
| 报告 | summary/recommendations/comparisons/goalPaths/candidateAudit/pendingQuestions/trace | 与固定决策、事实包、来源、赛道届次一致；资格、报名、准备程度分别表达 |
| 运行记录 | method/model/promptVersion/callCount/elapsedMs/inputTokens/outputTokens/costCny/fallback | 只记录实际调用；无 usage 留空，缺价格/账单不捏造费用；回退不计成 C 成功 |

机器契约见 `contracts.ts` 和 `catalog-types.ts`；跨对象校验见 `validation.ts`；目录等级门槛见 `catalog-validation.ts`。所有路径相对项目根目录 `src/lib/competitions/v6/`。

目录 L2/L3 是检查结果，人工审核与可发布状态另记。L2 至少需要有来源的身份范围、资格、任务、交付和入口，具体任务—能力—角色映射、六维价值及收益条件、三层难度、可检查体验动作。空数组、重复维度、泛化收益、关键未解决冲突不能充数。费用未知明确列入条件；只知道报名费，不能推断个人全部支出。已核实且适用于本人范围的当前个人必付下限高于明确上限时排除，学校代缴/团队费用不能直接当个人必付。

## 内容与扩库排期

1. 十条试点逐条固定届次、赛道和范围，三份深度稿先作为可审阅材料；当前达标数见实时审计，不把目标数量当实际完成。
2. 每五条为一批，累计审查目标依次 45、90、135；L3 目标 15、30、45。现有 135 条迁移记录都保留来源状态和阻塞项，没有批量虚构深度资料。
3. 原包二十个 P1 候选已建核验记录；只有核验完整且不重复的独立系列才能增量计数。当前未通过的候选不算新增。
4. 九任务族每族四个指定画像加四个特殊场景形成四十项清单；300/1000 元仅为测试条件。资格或个人总费用未知仅算条件候选，不能凑够“三个已满足系列、两种路径”。
5. 内容自动发现/提取结果进入差异提案，关键资格、费用、时间、交付仍待人工审核。历史资料可以保留准备价值，但不得显示当届可报名。

维护命令和源证据见 `catalog-maintenance.md`。当前来源审查由 AI 辅助完成，不能记成两人独立评审。

| 阶段 | 前置依赖 | 可审阅交付 | 放行条件 |
| --- | --- | --- | --- |
| 0 基线 | 原库、v1 包 | baseline-manifest、失败分类、迁移契约 | 原有 27 项失败保留并与新版增量分开 |

| 3 算法评测 | 固定画像/候选/事实包/报告数量 | A/B/C 调用管线、重复实验、配对区间、失败与成本记录 | 真实密钥/数据库、完整候选标注、独立评审；当前配置不具备实时模型实验条件 |

工程 20–35 人日仅保留为粗估；十试点真实审核完成后重估。每周八小时人工内容审核是资源假设，未以当前 AI 工作量折算成人工审核完成量。

## 验收口径

保留批准的目标：关键硬资格/关键虚构零例、抽取 micro-F1≥0.95、一般事实和引用支持精度≥98%、引用覆盖≥95%、解释完整≥95%、pooled nDCG@5≥0.85/@10≥0.80、C 相对最强基线提升≥0.03且配对95%区间下界>0、理解分≥85、合理下一步≥80%、快速路径完成率≥85%。

当前没有独立标签或真实学生数据，以上均不得写成已达标。模型五次重复先按同一画像汇总，再按独立画像族汇总；未标注为 U，不作为不相关；公开开发种子不进入封存验收。详见 `evaluation-protocol.md`、`review-guide.md`、`review-student-study.md`。

完整状态入口：`artifacts/v6/release-readiness.json`。浏览器验证与截图：`artifacts/v6/browser/verification.json`。目录计数与逐条缺口：`artifacts/v6/catalog-audit.json`。不对外发布，不更换生产默认排序，不修改冻结发布清单以绕过验收。
