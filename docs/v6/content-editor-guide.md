# 竞赛内容编辑与复核指南

本指南把原升级规格的术语和当前数据字段整理成编辑入口。它不是十项试点已完成、正式报名资格已通过或真人理解效果的证明。十个可复用样例及各自的来源边界见 `artifacts/continuation-20261105/pilot-priority-reconciliation-r1/template-10-mapping.json`；该组是本轮事后选出的审阅样例，不能回填为原先的试点记录。

## 十二模块

| 字段 | 学生应能回答的问题 | 编辑与复核重点 |
|---|---|---|
| `task` | 我实际要做什么？ | 写动作、处理对象和结果，不只复制赛事宗旨。 |
| `eligibility` | 我满足哪些报名条件，还有哪些未知？ | 学籍、年级、专业、年龄、地区等逐条关联适用原文。 |
| `track` | 哪个赛道对应我的任务？ | 分开赛道、组别及其要求，不继承不适用的父级规则。 |
| `participation` | 如何从当前阶段进入比赛？ | 区分校选、地区、全国阶段，以及个人、队友、导师和名额要求。 |
| `deliverables` | 要交什么，怎样判断做完了？ | 区分必交与选交，保留格式、数量和可检验的完成标准。 |
| `rubric` | 评委依据什么判断？ | 官方评分与编辑建议分开；缺权重就写未知。 |
| `skills` | 我可以承担哪个角色，需要什么证据？ | 连接任务、角色、技能和本人贡献，不把兴趣或团队成果当能力证明。 |
| `investment` | 全过程需要多少时间、钱和资源？ | 工时用带假设的编辑区间；费用拆清阶段、单位和承担者。未知不是零。 |
| `difficulty` | 入门、完赛、获奖分别难在哪里？ | 按画像和资源解释差距；不编造个人获奖概率。 |
| `benefits` | 可以保留什么成果，取得它有什么条件？ | 区分参与、完赛和获奖的收益，核对作品能否公开。 |
| `value` | 价值判断依据是什么？ | 六维分别给证据与限制，不合成全国通用“含金量分数”。 |
| `nextStep` | 下一步如何尝试、检查或退出？ | 七天体验和四周准备分别列动作、交付物、检查点、转向条件。 |

## 实体、主张与证据

`series → edition → track → group → scope → stage → milestone` 分别表示系列、届次、赛道、组别、适用范围、阶段和时间节点。一个系列的两个届次或赛道不能计作两个独立系列；发现平台、命题企业也不是新增赛事。更名或合并必须有连续性证据。

| 术语 | 应如何使用 |
|---|---|
| `official_fact` | 适用正式规则支持的事实；学校校选通知只在其范围内成立。 |
| `organizer_claim` | 主办方的宣传或效果主张，不因此证明就业、升学或能力收益。 |
| `editorial_inference` | 明确写出依据、假设和不确定性，例如角色建议、准备工时区间。 |
| `participant_report` | 参与者经验可提示常见困难，不能单独决定资格或官方评分。 |
| `unknown` | 尚无足够依据；说明缺什么和下一步来源，不用空白掩盖。 |
| `historical` | 有证据但仅适用旧届；可作学习材料，不能自动批准新届报名。 |
| `conflicting` | 证据相互冲突；保留各方原件、范围与时间，等待裁决。 |
| `not_applicable` | 有依据认定该字段不适用，不能替代未查到资料。 |

每条关键事实绑定具体实体、来源正文、位置、原始字节摘要、适用时间和复核时间。来源保存成功或摘要相等只证明取到了相同字节，不证明事实适用。只有月份的日期不得编造某一天；正文更新日与网页最初创建日应分别记录。

费用核验须区分报名费、晋级费、材料、工具、网络、设备、差旅等适用项目。不能从“免报名费”推出个人总成本为零，也不能假设报销、平摊、已有软件许可或已有网络。供应商公开价格是价格依据，不是主办方资格规则。正式参赛计划v5 R3合同已完成专项独立复审；某条具体计划仍须另有资格、费用、资源和完整工时依据，合同通过不代表原40画像已覆盖。

## 等级与用途

L1要求身份、适用对象、任务、来源和时间状态明确，关键未知显式保留，只用于有条件探索。L2要求十二模块有实质回答或有理由的未知，并具备关键资格、交付和任务依据。L3还需代表性题目或完整公开作品、评分或要求映射、角色路径及经审建议。

结构等级、内容批准和“现在可报名”是不同判断。按用户已确认的续做口径，正式参赛规划覆盖可以包含规则和赛程已公布、报名尚未开启的具体正式届次；当前开放报名另按72小时复核。历史练习不代替正式参赛，未知资格、个人全部费用或资源不能计通过。

原135系列逐项保留核验或降级依据。新增系列数、原20个优先候选的核验决定、全部扩展发布数分别统计；`publishedExpansionCount` 不能直接解释为原20项中的通过数。

## 十样例验证与修改流程

1. 冻结样例内容摘要、题目或作品原件、角色和来源范围，再分开作者与两位评审上下文。
2. 模拟阅读者实际阅读该版本，回答“实际任务、可承担角色、主要缺口、条件性收益”四项。保存原始回答和独立核验，不能用内容审核的“有用”布尔值代替理解观测。
3. 发现问题时保留原稿和失败记录，修改内容后重新计算摘要。旧批准不自动继承；新摘要经过双审后才进入审核账本。
4. 记录本次实际工作会话的开始、结束、活动范围、产物、返工和中断；并行会话不得相加当人工工时。不从文件mtime或抓取间隔倒推历史编辑耗时。
5. 正式12次试验及60个独立模拟画像可以按预注册映射复用真实观测；覆盖不到的样例继续待验证，不额外添加“每样例60人”条件。

本轮十样例已取得原始回答和独立核验：一个隔离AI上下文连续阅读十份，另一隔离上下文核验，十份均能回答四要点；这不是十位独立参与者或正式60画像实验。生产浏览器正文与该次阅读输入相同。历史逐项编辑工时仍缺，不能倒推补齐。本次反馈修订会话另有实际时间记录；三条旧草稿措辞的删改已由两个新的隔离上下文重新读取来源并批准新摘要，六条审查已导入账本，45个已审L3系列保持有效。原阅读回答不回改，修订后的生产页面另行复验。

## 本轮理解反馈形成的编辑检查表

以下是可复用的排版与核验规则，具体赛事数值必须重新引用其对应来源，不把样例数值套用到其他赛事。

| 检查点 | 编辑动作 |
|---|---|
| 提交与本人声明 | 将本人问答、AI披露、身份例外及独立完成要求放在提交清单附近；未读到的要求继续标未知。 |
| 本人产出与公开展示 | 将可复算、可演示的本人工作和对外展示所需授权分别列出，避免把训练成果自动说成可公开作品。 |
| 多阶段交付 | 按阶段、任务和载体分别列时间、件数、规格及误差，不能把教案、视频、现场或基本/发挥任务合成一个阈值。 |
| 示例身份 | 公开论文、专题收录或创作示例的标题旁说明已核实的身份；没有编号或奖项依据就不暗示获奖。 |
| 入口与范围 | 将校选交付、后续赛段未知和当届入口/截止/年龄等核验事项列开；校赛通知不能证明国赛通道。 |
| 证据递进 | 区分纸面计划、实际重复记录、本人解释与回应质疑；角色轮换或课堂演练不能直接产生报名资格。 |
| 审核状态 | 展示状态应来自确切记录摘要对应的审核账本；不要在长期内容中固化“作者草稿待双审”。删除旧措辞也须生成新摘要并双审，其他缺口继续保留。 |

七项非阻断的个别页面排版建议已进入上述模板检查表；没有观察到相应关键理解错误，暂不据此增加或改写赛事事实。三页确切审核状态混淆优先修订，原阅读回答及评审不回改。AI代理数据只证明相应模拟范围下的结果，真人参与人数和真人效果继续单列。
